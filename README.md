# Video_Tiktok Web Portal

Official landing page, Terms of Service, Privacy Policy, and OAuth Redirect Receiver for Video_Tiktok.

Built to comply with **TikTok for Developers Content Posting API & Login Kit** audit requirements.

## Features
- Full Light / Dark mode toggle with persistent local storage.
- Compliant Terms of Service.
- Compliant Privacy Policy with User Data Deletion Instructions.
- OAuth callback handler for TikTok login kit.
- Zero-dependency static site, deployable anywhere in seconds (Vercel, Render, GitHub Pages).
